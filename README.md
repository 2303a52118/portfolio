# Pochampally Sravan - Portfolio

Static site. Open `index.html` in a browser, no build step needed.

```
portfolio/
  index.html          page content
  css/style.css       styles and colour tokens (:root)
  js/script.js        theme toggle, active menu link, raindrop reveal, back-to-top
  images/
    profile.jpg       About-section photo (replace to change it)
    education-logo.png  logo beside the Education card
```
